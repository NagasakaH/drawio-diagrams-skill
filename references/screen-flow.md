> 実行はすべて `node scripts/drawio-cli.mjs screen-flow ...` 経由。

# 画面遷移図生成スキル (`drawio-screen-flow`)

JSON spec を描画して `.drawio` XML および `.drawio.png`（元XML埋め込み済み・draw.io再編集可能）を
生成する。Pure Node.js (.mjs) のみで動作し、外部 npm 依存はゼロ。
Web / アプリの画面をミニブラウザ風のカード（画面名 + ルート + 主要要素リスト）として描き、
トリガー名付きの矢印で遷移を結ぶ。モーダル・エラー画面・外部リンク・アクセス権区分まで
1 枚に落とせる。

---

## デフォルトの描画方針

- **レイアウト**: spec の `row` / `col` を優先（0 始まり整数）。主導線は 1 行に左→右で並べ、
  モーダルやエラーはその上下の行に置くと線が交差しにくい。水平間隔 168px・垂直間隔 118px 基準。
- **画面カード**: `swimlane` のヘッダーバー（画面名 + 種別タグ）+ ルート行（等幅フォント、
  `/orders/:id` など）+ 要素の箇条書き + 補足ノート（イタリック下段）。
  幅は要素の最長行から自動（216〜330px）。
- **種別ごとの配色**:
  - `screen` … 緑 (`#059669`) の実線ヘッダー
  - `modal` … 紫 (`#7C3AED`) の破線枠
  - `error` … 赤 (`#DC2626`) の破線枠（403 / 404 / 失敗トースト）
  - `external` … グレー (`#64748B`) の破線枠（外部ドメインへ離脱する画面）
- **アクセス区分**: `groups[]` を極薄緑の破線枠で描き、左上に `[access] ラベル`。
  メンバーは `screens[].group` からも暗黙に枠を作る。
- **遷移線**: orthogonal 配線。行内で右から左へ戻る線（戻る / パンくず）は行下部の廊下を通し、
  ラベルは廊下の下に出す。途中のカードを貫く縦線は右側大きくで回り込ませる。
  自己遷移（同じ画面内の再表示など）はカード右側のループになる。
- **ラベル**: トリガー名（`行をクリック`、`返金確定 / 200`）を `labelBackgroundColor=#FFFFFF` 付きで
  線の実側へ。同一辺に複数本ある場合は沿線方向と上下へ分散する。
- **ヘッダー**: 左端アクセントバー (#059669) + 左寄せタイトル / サブタイトル + 細区切り線、
  右上に凡例（通常画面 / モーダル / エラー / 外部、通常遷移 / モーダル表示 /
  エラー・リダイレクト / 外部遷移、アクセス区分枠）。

## 実行手順

### 1. JSON spec から直接描画（最短1コマンド）

```bash
node scripts/drawio-cli.mjs screen-flow \
  --spec /path/to/screen-flow-spec.json \
  --output /path/to/screen-flow.drawio.png
```

`--output` から `.drawio` XML のパスを自動決定する（`xxx.drawio.png` → `xxx.drawio`）。
明示指定は `--xml-out`、タイトル上書きは `--title` / `--subtitle`、PNG解像度は `--scale`（既定 2）。
`--no-png` で XML のみ生成も可。`.svg` 出力は出力拡張子で自動判定。

### 2. 実画面から起こす手順

1. ルーティング定義（Next.js の pages / App Router、React Router の配列など）から画面を書き出す。
2. 各画面に `route` を入れる（`/orders/:id`、モーダルは `modal · /orders/:id/refund`、
   トーストは `toast · order.updated` のように前置きを付けると読みやすい）。
3. `elements` は「その画面で操作できるもの」を 3〜6 個に絞る（長すぎるとカードが縦長になる）。
4. 遷移は `label` に **ユーザー操作 + 結果** を書く（`行をクリック`、`返金確定 / 200`）。
5. 認証前 / 認証後など区分があれば `groups` で括る。外部 IdP への離脱は `kind: "external"`。

### 3. 目視検証（必須）

生成された `.drawio.png` を画像読み込みで確認し、カード内のテキスト切れ・線とカードの重なり・
ラベル同士の衝突をチェックしてからユーザーへ報告する。
`node scripts/check-layout.mjs <生成 .drawio>` で機械検査もできる。

# JSON spec リファレンス (`drawio-screen-flow`)

`build-screen-flow.mjs --spec` に渡す JSON の形式。最上位キーは `title` / `subtitle` / `groups` /
`screens` / `transitions`。必須は `screens` のみ（空配列はエラー）。
`transitions` の別名として `flows` も受けつける。

```json
{
  "title": "管理ポータル 画面遷移図",
  "subtitle": "1行の補足説明（任意）",
  "groups": [
    { "id": "public", "label": "認証前 (Public)", "kind": "access" }
  ],
  "screens": [ ... ],
  "transitions": [ ... ]
}
```

## `screens[]` — 画面カード

| フィールド | 必須 | 説明 |
| --- | --- | --- |
| `id` | ○* | 図内一意の参照キー（`transitions` から参照）。*`name` だけで書くことも可 |
| `name` | ○ | ヘッダーバーに表示する画面名 |
| `route` | | ルートまたは識別子（`/orders/:id`）。ヘッダー下に等幅フォントで表示 |
| `kind` | | `screen`（既定）/ `modal`（`dialog` `sheet` も可）/ `error`（`403` `404` `failure`）/ `external`（`third-party`） |
| `group` | | 所属区分の `id`。`groups[]` に無い id なら暗黙に枠を追加 |
| `elements` | | 箇条書きで並べる主要要素（文字列配列）。長さは自動折り返し |
| `note` | | カード下段にイタリックグレーで出す補足（権限条件・ページサイズ等） |
| `row` / `col` | | グリッド配置（0 始まりの整数）。未指定は自動 |

### kind と描画

| `kind` | ヘッダー色 | 枠 | ヘッダー右端のタグ |
| --- | --- | --- | --- |
| `screen` | `#059669` | 実線 | `画面 ●` |
| `modal` | `#7C3AED` | 破線 | `モーダル ●` |
| `error` | `#DC2626` | 破線 | `エラー ●` |
| `external` | `#64748B` | 破線 | `外部 ↗ 外部` |

- 要素もルートも無い画面は描けるが、最低 1 行の箇条書きが入る。
- `elements` を 7 行以上にするとカードが縦長になり、横のカードと高さがずれて見にくくなる。
  詰められるものは `note` に逃がす。

## `transitions[]` — 遷移矢印

| フィールド | 必須 | 説明 |
| --- | --- | --- |
| `from` | ○ | 開始画面の `id` |
| `to` | ○ | 遷移先画面の `id`（同じ id を書くと自己ループ） |
| `label` | | トリガー名。別名 `trigger` / `event` も可 |
| `kind` | | `normal`（既定）/ `modal` / `error` / `external` |

| `kind` | 描画 | 使いどころ |
| --- | --- | --- |
| `normal` | 緑実線 (`#0F766E`) + 塗り三角 | 画面切り替え・確定遷移 |
| `modal` | 紫破線 + 塗り三角 | モーダルの開閉 |
| `error` | 赤破線 + 塗り三角 | 権限エラー・API 失敗・再試行 |
| `external` | グレー破線 + open arrow | 外部ドメインへの離脱 |

- `from === to` の自己遷移（バリデーション再表示など）はカード右側のループになり、
  ラベルはカードの外側に出る。
- 同じ画面ペアの往復は自動的にラベルを上下（左右）へ分ける。

## `groups[]` — アクセス区分の破線枠（任意）

| フィールド | 必須 | 説明 |
| --- | --- | --- |
| `id` | ○ | `screens[].group` から参照される id |
| `label` | | 枠左上に表示するラベル（既定は `id`） |
| `kind` | | 前置ラベル。`access` にすると `[access] 認証後 (Authenticated)` のように付く |

枠はメンバー画面の外接矩形を内包するよう自動計算される（左右 30px・上 34px・下 26px の余白）。
